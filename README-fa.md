# اسکنر نوبیتکس

نسخه موبایل‌محور برای رتبه‌بندی بازارهای نوبیتکس بر اساس چند عامل تکنیکال و جریان سفارش.

## اجرا
```bash
npm install
npm start
```
سپس `http://localhost:10000` را باز کنید.

## نکته
این پروژه ابزار تحلیل احتمالاتی است و تضمین سود یا پیش‌بینی قطعی ارائه نمی‌کند.
برای Render کافی است Build Command را `npm install` و Start Command را `npm start` قرار دهید.
